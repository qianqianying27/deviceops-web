# PLC 故障代码对照表（节选）

| 代码 | 含义 | 可能原因 | 处理建议 |
|---|---|---|---|
| E-102 | 温度传感器断线 | 热电偶开路、接线松动 | 断电后测阻值，紧固端子或更换传感器 |
| E-205 | 合模未到位 | 模内有异物、顶针未复位 | 清理模具，手动复位顶针 |
| E-311 | 液压油温过高 | 冷却器堵塞、油质劣化 | 停机冷却，清洗冷却器并换油 |
| E-402 | 通信超时 | 网线松动、从站掉电 | 检查网线与从站电源，重连后确认数据刷新 |
| E-517 | 伺服过载 | 负载卡滞、参数不匹配 | 降低负载，核对伺服参数与报警历史 |
| E-730 | 安全门未闭合 | 门开关损坏、门体变形 | 更换门开关，检查门体与限位 |

## 处置通用原则
1. 先确认报警是否为瞬时抖动：连续出现 3 个采样周期才判定为真实故障。
2. 任何带电检查前执行挂牌上锁（LOTO）。
3. 处置完成后必须记录：报警代码、发生时间、更换件、恢复时间。
4. 同一代码 24 小时内重复出现 2 次以上，升级为工单并安排专项排查。
