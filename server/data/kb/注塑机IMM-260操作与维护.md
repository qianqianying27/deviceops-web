# 注塑机 IMM-260 操作与维护手册（节选）

## 1. 正常运行参数
- 料筒温度：一区 210±10℃，二区 230±10℃，喷嘴 225±10℃。
- 液压油温：40–55℃，超过 60℃ 需降负荷并检查冷却器。
- 合模压力：≤ 140 bar，异常升高优先检查模具与导轨润滑。

## 2. 温度异常处理
1. 温度高于设定值 15℃ 且持续 5 分钟：先将加热圈断电，保持螺杆低速运转，避免局部碳化。
2. 检查热电偶接线与补偿导线，排除测温误差。
3. 冷却水路流量低于 8 L/min 时，清理过滤器并排气。
4. 处理后空打 3–5 模，确认料流正常再恢复生产。

## 3. 日常点检
- 每班检查润滑油位、油压表读数、急停按钮。
- 每周清理料斗磁架、检查加热圈紧固。
- 每月校验安全门开关与液压油清洁度。

## 4. 常见故障代码
- E-102：料筒温度传感器断线。断电后测量热电偶阻值，正常应小于 20Ω。
- E-205：合模未到位。检查模具内是否有异物、顶针是否复位。
- E-311：液压油温过高。停机 30 分钟，清洗冷却器并检查油质。
