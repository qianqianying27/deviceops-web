# 螺杆空压机 AC-75 点检与安全规程（节选）

## 1. 运行监控指标
- 排气温度正常 75–95℃，超过 105℃ 触发高温报警并停机。
- 排气压力 0.6–0.8 MPa，压力波动超过 0.1 MPa 需检查进气阀与卸载阀。
- 振动速度有效值 ≤ 7.1 mm/s；超过 11 mm/s 判定为危险，需立即停机。

## 2. 高温报警处置
1. 确认冷却风扇运行、散热器无遮挡、环境温度低于 45℃。
2. 检查油位与油品：油位低于下限时补充同牌号润滑油，油品乳化需整体更换。
3. 清理油冷却器与空气过滤器，压差大于 0.2 MPa 时更换滤芯。
4. 复位后空载运行 10 分钟，排气温度稳定在 95℃ 以下方可加载。

## 3. 振动异常处置
- 振动突增先检查地脚螺栓与减震垫，其次检查联轴器对中。
- 伴随异响与电流上升时，判定为轴承磨损，转入维护状态并开单更换轴承。

## 4. 安全要求
- 任何检修前必须断电、挂牌、泄压至 0 MPa。
- 禁止带压拆卸油管；冷却后油温低于 40℃ 才可排油。
